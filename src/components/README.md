# IT313 Lab 6 – Student Directory Viewer

## Project Description

The Student Directory Viewer is a React Native application built using Expo. It displays a list of students with their names, year levels, and personal photos.

## Features

- Displays five student profiles.
- Uses reusable StudentCard components.
- Searches students by name.
- Filters names without case sensitivity.
- Allows users to flag or unflag students for advising.
- Uses local image files for student photos.
- Uses ScrollView to display the student list.

## Technologies Used

- React Native
- Expo
- TypeScript
- Visual Studio Code

## How to Run

1. Install the project dependencies using `npm install`.
2. Start Expo using `npx expo start`.
3. Scan the QR code using Expo Go.

## Components

- StudentDirectory – manages the student list, search, and flag states.
- StudentCard – displays each student's information and flag button.
